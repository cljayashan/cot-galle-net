How to use this material

1. Read a topic

Each page is one short topic with diagrams. Work through the units in order using the sidebar or the Next button.

2. Try the commands

Type the commands and configurations yourself in a virtual machine or Packet Tracer. The labs need only free software.

3. Use the interactive labs

Subnet calculator, VLSM planner, binary and IPv6 converters, transfer-time calculator and a port quiz help you practise.

4. Check yourself

Each unit ends with a hands-on lab and review questions with answers. Pages you open get a tick in the menu and on the unit cards.
