9.5Common faults and fixes

SymptomLikely causeFix
169.254.x.x addressDHCP server unreachableCheck cable/Wi-Fi, DHCP service and scope; renew lease
Can ping IP but not nameDNS problemCheck client DNS settings, DNS server status, nslookup, flush cache
Can reach local hosts, not InternetWrong or missing gateway, ISP faultCorrect gateway, check router and WAN link
Intermittent connectionBad cable, Wi-Fi interference, duplex mismatchReplace cable, change channel, set speed/duplex
IP conflict messageTwo devices with same IPUse DHCP reservations, find the device with arp -a
Website down, server pings fineWeb service stopped or port blockedsystemctl status, check firewall and port 80/443
Cannot SSH or RDPService off, firewall, wrong port or credentialsCheck service, ss -tulpn, firewall rules, logs
Certificate warningExpired or mismatched certificate, wrong date on clientRenew certificate, check name and system clock
Server slowCPU, RAM or disk exhausted, too many connectionstop, df -h, find the process, add resources
Server will not bootBad disk, corrupt update, wrong boot orderBoot recovery media, check disk health, restore from backup
Application crashes after updateIncompatible version, missing dependencyRead logs, roll back, reinstall dependency
Cannot send emailWrong MX/SMTP settings, port 25 blocked, SPF failureCheck DNS records, mail logs, firewall
