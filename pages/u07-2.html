Unit 7 · Domain Name System (DNS)

7.2DNS architecture

The namespace is an inverted tree:

  • Root (.): 13 logical root server addresses (A to M), operated by many organisations with many mirrored instances.
  • Top-Level Domains (TLD): generic (.com, .org, .net), country-code (.lk, .uk, .in) and newer generic TLDs such as .app and .shop.
  • Second-level domain: the registered name (example in example.com).
  • Subdomain / host: www, mail and so on.

A Fully Qualified Domain Name (FQDN) names a host completely: www.example.com. (the trailing dot is the root).

A zone is the portion of the namespace administered by one set of name servers; a zone file holds its records.

DNS server roles

RoleFunction
Authoritative serverHolds the official records for a zone (primary/master and secondary/slave, kept in sync by zone transfer)
Recursive resolverAsks other servers on the client's behalf and caches answers (your ISP, 8.8.8.8, 1.1.1.1)
Caching serverStores answers for the record's TTL to speed up repeated lookups
ForwarderPasses queries it cannot answer to another resolver
Root and TLD serversDirect resolvers down the tree

Hierarchy keeps the system scalable

No single server holds every name on Earth. Authority is delegated down the tree: root → TLD (.lk, .com) → organisation (school.lk) → hosts (www.school.lk). Each zone is a slice of that tree managed by a set of authoritative name servers.

Roles you must separate mentally

  • Authoritative server: answers for zones it owns ("I am the official source for school.lk").
  • Recursive resolver: does the walking of the tree for the client and caches answers (ISP DNS, 1.1.1.1, a local BIND resolver).
  • Forwarder: a resolver that hands hard work to another resolver (common on small internal DNS servers).

Primary (master) holds the writable zone data; secondaries (slaves) copy it with zone transfers so the domain still resolves if one server dies.

Remember

  • DNS is hierarchical: root, TLD, domain, host.
  • Authoritative ≠ recursive; many problems come from mixing those roles carelessly (open resolvers).
