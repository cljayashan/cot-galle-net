Unit 8 · Network Security

8.1Why security settings matter

Servers hold valuable data and run critical services, and they are attacked continuously. Security settings protect the CIA triad:

  • Confidentiality: only authorised people can read data.
  • Integrity: data is not changed without detection.
  • Availability: services are usable when needed.

Common threats: malware and ransomware, phishing, brute-force password attacks, unpatched vulnerabilities, denial of service (DoS/DDoS), man-in-the-middle attacks, misconfiguration and insider misuse.

Essential security settings checklist (server hardening)

  • Keep the OS and applications patched; enable automatic security updates.
  • Remove unneeded software and disable unused services and ports.
  • Use strong passwords and multi-factor authentication; lock out repeated failures.
  • Apply least privilege: normal accounts for daily work, administrator rights only when required; disable direct root/Administrator login over the network.
  • Use SSH keys, change default accounts and passwords on all devices.
  • Enable the host firewall and a network firewall.
  • Use encryption: HTTPS/TLS for services, disk encryption, encrypted backups.
  • Enable logging and monitoring and review logs; synchronise time (NTP) so logs agree.
  • Use antimalware and, where suitable, intrusion detection (IDS/IPS).
  • Keep tested backups (the 3-2-1 rule: 3 copies, 2 media types, 1 off-site).
  • Separate networks (VLANs, DMZ) and restrict management access.
