Unit 6 · Virtual Private Network (VPN)

6.6Quick set-up outline (WireGuard on Ubuntu)

Terminal
sudo apt install wireguard -y
umask 077                            # new files readable only by you
wg genkey | tee server.key | wg pubkey > server.pub
sudo nano /etc/wireguard/wg0.conf    # add the [Interface] and [Peer] sections shown below
sudo wg-quick up wg0
sudo wg show

The [Interface] section holds the server's private key, tunnel address (for example 10.8.0.1/24) and listening port; each [Peer] holds a client's public key and allowed IP. Open the UDP port on the firewall (sudo ufw allow 51820/udp) and, if clients must reach the LAN behind the server, enable IP forwarding (net.ipv4.ip_forward=1 in /etc/sysctl.conf).

Configuration file
[Interface]
Address    = 10.8.0.1/24
ListenPort = 51820
PrivateKey = <contents of server.key>

[Peer]
PublicKey  = <the client's public key>
AllowedIPs = 10.8.0.2/32
