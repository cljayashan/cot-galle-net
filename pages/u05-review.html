Self-check questions

Write your answers first, then open the answers to check them.

  1. Give three differences between a desktop OS and a server OS.
  2. Compare shared hosting and a VPS.
  3. A company needs a server for a busy online shop with traffic spikes. Which option would you suggest and why?
  4. Which port and protocol are used by SSH, HTTPS and DNS?
  5. Why should password login be replaced by key-based login on SSH?
  6. What does the command ss -tulpn show?
  7. State two post-installation tasks you must do on every new server.
Show answers

  1. A server OS supports multiple simultaneous remote users and services, offers roles/services such as DNS and AD, has stronger remote management and security, supports server-grade hardware and is built for continuous uptime. (Any three.)

  2. Shared: many sites on one OS, no root access, cheapest and limited control. VPS: isolated virtual machine with its own OS and root access, more resources and flexibility, somewhat higher cost.

  3. A cloud server or auto-scaling VPS cluster, because it can scale up for traffic spikes and be billed by use; add load balancing and backups.

  4. SSH 22 (TCP); HTTPS 443 (TCP); DNS 53 (UDP, TCP for large replies/zone transfers).

  5. Keys are far harder to guess or brute-force than passwords and cannot be captured by typing; password login can then be disabled.

  6. It lists listening TCP/UDP ports and the programs using them.

  7. Apply updates, set a static IP/hostname, enable firewall, create a non-admin account, disable unneeded services, take a backup (any two).
