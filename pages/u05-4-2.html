Unit 5 · Server Installation, Setting Up and Configuration

5.4.2Practical: Ubuntu Server and a static IP

Practical: install Ubuntu Server in VirtualBox

  1. Create a VM: 2 CPUs, 2 GB RAM, 20 GB disk, network in Bridged or NAT with port forwarding.
  2. Mount the Ubuntu Server ISO and start the VM.
  3. Follow the installer; tick Install OpenSSH server.
  4. After reboot log in and run:
Terminal
sudo apt update && sudo apt upgrade -y
hostnamectl set-hostname server1
ip a

Setting a static IP on Ubuntu (Netplan)

Edit the YAML file in /etc/netplan/ (for example 00-installer-config.yaml or 50-cloud-init.yaml; the name depends on the Ubuntu version):

YAML
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: false
      addresses: [192.168.1.10/24]
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]

Test the change with sudo netplan try (it rolls back automatically if you lose the connection), then make it permanent with sudo netplan apply.

YAML indentation matters: use spaces, never tabs. The interface name (enp0s3 here) must match the name shown by ip a.
