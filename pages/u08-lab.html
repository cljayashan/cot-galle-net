8.6Hands-on lab: Firewalls and cryptography

Do these tasks on your own computer or in the lab using free software. Write down what you see at each step: your notes are useful evidence for assessments and for revision.

Ethics: scan, test and attack only machines in your own lab. Scanning other people's systems without written permission is illegal in many countries.

  1. Enable UFW on an Ubuntu VM with default deny; allow only SSH and HTTP; test from another machine with nmap (own lab only).
  2. Create a firewall rule on Windows to block ping (ICMP), test, then remove it.
  3. Encrypt a file with a password using openssl enc -aes-256-cbc -salt -pbkdf2 -in a.txt -out a.enc, then decrypt it.
  4. Generate an RSA key pair, sign a file with the private key, and verify with the public key (openssl dgst -sha256 -sign and -verify).
  5. Open a HTTPS site in a browser, view the certificate and write down issuer, validity and the chain.
Terminal
# encrypt and decrypt a file with a password (AES-256)
openssl enc -aes-256-cbc -salt -pbkdf2 -in a.txt -out a.enc
openssl enc -d -aes-256-cbc -pbkdf2 -in a.enc -out a-decrypted.txt

# create a key pair, sign a file and verify the signature
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out private.pem
openssl pkey -in private.pem -pubout -out public.pem
openssl dgst -sha256 -sign private.pem -out a.sig a.txt
openssl dgst -sha256 -verify public.pem -signature a.sig a.txt
