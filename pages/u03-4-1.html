Each layer in plain words

  • 7 Application: the network services that programs use: HTTP for the web, SMTP for email, DNS for names. It is not the program itself; the browser uses HTTP.
  • 6 Presentation: makes sure both sides understand the data format. It deals with character sets, compression and encryption (TLS is often placed here).
  • 5 Session: starts, manages and ends conversations between applications, for example keeping a login session open.
  • 4 Transport: delivers data from one application to another. It adds port numbers, and for TCP it adds reliability: acknowledgements, retransmission and ordering (see 3.3.1).
  • 3 Network: delivers packets from one host to another, across many networks, using IP addresses. Routers work here.
  • 2 Data link: delivers frames from one device to the next device on the same link, using MAC addresses, and detects errors with a CRC. Switches work here.
  • 1 Physical: sends the raw bits as electrical signals, light pulses or radio waves. Cables, connectors, hubs and repeaters work here.

Remember

  • Seven layers: Physical, Data link, Network, Transport, Session, Presentation, Application.
  • Switches use MAC addresses at layer 2; routers use IP addresses at layer 3; ports are at layer 4.
  • Each layer serves the one above it and uses the one below it.
