Unit 5 · Server Installation, Setting Up and Configuration

5.3Server hosting and deployment options

OptionDescriptionAdvantagesDisadvantagesTypical use
Dedicated serverA whole physical machine for one customerFull performance, control and isolationExpensive, you manage hardware or pay for itLarge databases, high-traffic sites
Shared hostingMany customers share one server and its resourcesVery cheap, no server managementLimited control, neighbours can slow you, limited securitySmall websites, blogs
Virtual Private Server (VPS)One physical machine divided into isolated virtual machines, each with its own OS and root accessGood balance of cost and control, scalableShares hardware, performance can varySmall to medium business apps
Cloud serverVirtual servers in a provider data centre, billed by use (AWS, Azure, Google Cloud)Elastic scaling, high availability, pay as you goCosts can grow, depends on providerVariable or global workloads
On-premises serverOwned and run in your own server roomFull control of dataCapital cost, power, cooling, staffSensitive data, local services
ColocationYour own server hosted in a provider's data centreProvider power, cooling and bandwidthHardware cost remains with youCompanies needing own hardware

Key words in this topic

  • On-premises: servers in your own building.
  • Colocation: your hardware in a provider's data centre.
  • Shared hosting / VPS / cloud / dedicated: increasing control and (usually) cost.
  • RAID: disk redundancy or speed; not a substitute for backups.
