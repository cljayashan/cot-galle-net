2.3Classification by role

Peer-to-peer (P2P): every computer is both client and server. Cheap and simple, but difficult to secure and manage; suitable for fewer than about ten computers.

Client-server: dedicated servers provide services (files, web, email, DNS) to clients. Offers centralised security, backup and control; requires a more skilled administrator and higher cost. This is the model on which the rest of this module is built.

Peer-to-peer in detail

In a peer-to-peer network (often called a workgroup in Windows), every computer is equal. Each one keeps its own user accounts and decides itself what to share. To share a folder, its owner sets permissions on their own PC.

  • Good for: a home or a very small office with a few computers and no IT staff.
  • Problems as it grows: every user needs an account on every PC they use; there is no single place for backups; a shared file disappears when the PC holding it is switched off; and security depends on every user setting things up correctly.

File-sharing apps such as BitTorrent also use a peer-to-peer design, at Internet scale.

Client-server in detail

In a client-server network, servers are powerful, always-on computers that provide services, and clients are the computers people use, which request those services.

  • Central accounts: with a directory service such as Active Directory, each user has one account that works on every PC (see 5.2).
  • Central data: files are stored on a file server, which is backed up every night.
  • Central security: the administrator controls permissions, updates and policies for everyone.
  • Scalability: adding a hundred more users means adding client PCs and perhaps more server capacity, not reconfiguring every machine.

The cost is the server hardware and software, and a skilled administrator. The servers are also important single points: if the only file server fails, nobody can open their files, so important servers need redundancy and backups.

Everyday example: when you open a website, your browser is a client and the web server is the server. The same model is used by email, online banking and streaming services.

Remember

  • Peer-to-peer: every computer is equal; cheap but hard to manage and secure.
  • Client-server: dedicated servers provide central services, security and backup.
