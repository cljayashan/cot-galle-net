Unit 8 · Network Security

8.5.2How a browser trusts an HTTPS site

  1. The browser connects to the server on port 443 and says which TLS versions and ciphers it supports.
  2. The server sends its certificate.
  3. The browser checks the CA signature and chain, the validity dates, and that the certificate name matches the domain.
  4. The browser and server agree on a session key using asymmetric key exchange.
  5. Both switch to symmetric encryption (for example AES) for the rest of the session.
