3.4.3Encapsulation

When sending, each layer adds its own header: data becomes a segment (transport header with ports), then a packet (IP header with IP addresses), then a frame (MAC header and CRC trailer), then bits. The receiver reverses the process (de-encapsulation).

Following one web request

You type www.example.com and press Enter. On your PC:

  1. Application: the browser creates an HTTP request: "GET / please".
  2. Transport: TCP adds a header with the source port (a random high number, such as 51000) and the destination port (443 for HTTPS), plus sequence numbers. The data is now a segment.
  3. Internet: IP adds a header with your PC's IP address and the server's IP address. It is now a packet.
  4. Network access: Ethernet adds a header with your PC's MAC address and the MAC address of the default gateway (not the server!), plus a CRC trailer. It is now a frame, sent as bits on the cable.

At every router on the way, the frame header is removed and a new frame header is added for the next link. The IP addresses stay the same from end to end, but the MAC addresses change on every hop. At the server, each layer removes its own header and passes the rest up (de-encapsulation) until the web server software receives the original HTTP request.

Overhead

Every header adds bytes that are not your data. A full-size Ethernet frame carries 1,500 bytes of payload; the TCP and IP headers use at least 40 of those, and Ethernet adds its own header, trailer and framing on the wire. That is one reason why throughput is always a little lower than bandwidth (see 1.7).

Analogy: a letter (data) goes into an envelope with the department name (port), which goes into a bigger envelope with the company's address (IP), which a courier puts in a bag labelled for the next depot (frame). At each depot the bag is changed, but the address on the envelope never changes.

Remember

  • Data, then segment, then packet, then frame, then bits.
  • IP addresses stay the same end to end; MAC addresses change at every router.
  • The receiver removes the headers in reverse order (de-encapsulation).
