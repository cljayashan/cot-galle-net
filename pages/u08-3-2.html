8.3.2Asymmetric (public-key) encryption

A key pair is used: a public key (shared with everyone) and a private key (kept secret). What one key encrypts, only the other can decrypt.

  • Algorithms: RSA (2048-bit or more), ECC (elliptic curves), Diffie-Hellman for key exchange.
  • Encryption for confidentiality: the sender encrypts with the receiver's public key; only the receiver's private key can decrypt.
  • Advantage: solves key distribution; supports digital signatures.
  • Disadvantage: much slower than symmetric encryption.
