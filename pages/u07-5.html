Unit 7 · Domain Name System (DNS)

7.5Configuring a DNS server

A DNS server can be built on Linux with BIND9 or on Windows Server with the DNS Server role. The pages below configure the same example zone, school.lk, on both, then add a reverse zone, test the server and protect it.

Key words in this topic

  • Forward zone: name → IP (e.g. school.lk).
  • Reverse zone: IP → name (1.168.192.in-addr.arpa).
  • Primary / secondary: where the data is edited vs copied.
  • Forwarder: where your server sends queries it cannot answer authoritatively.
