8.3.4Hashing

A hash function (SHA-256, SHA-3) turns any data into a fixed-length digest. It is one-way (cannot be reversed), and any tiny change in the data gives a completely different digest. Uses: file integrity checks, password storage (with a unique salt and a deliberately slow algorithm such as bcrypt or Argon2), and digital signatures. MD5 and SHA-1 are broken and should not be used for security.

Terminal
sha256sum file.iso            # Linux
Get-FileHash file.iso         # Windows PowerShell
