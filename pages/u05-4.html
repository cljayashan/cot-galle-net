Key words in this topic

  • Windows Server: GUI, Active Directory, IIS; licensed + CALs.
  • Linux Server: Ubuntu, RHEL family; strong on web, DNS, cloud and containers.
  • Server Core / minimal install: fewer packages = smaller attack surface.
  • Hypervisor: runs virtual machines that each have their own OS.

Picking an OS for class projects

For this diploma, Ubuntu Server in a VM is the fastest path to SSH, Apache, BIND and WireGuard practice at zero licence cost. Use Windows Server evaluation ISOs when you must practise Active Directory, GUI roles or PowerShell remoting. Hypervisors let you run both side by side without buying extra PCs.
