7.5.3Reverse zones, management and testing

Reverse lookup zones

For the 192.168.1.0/24 network the reverse zone is 1.168.192.in-addr.arpa; PTR records map the last octet to a name.

Configuration file
zone "1.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192.168.1";
};
DNS zone file
$TTL 3600
@   IN SOA ns1.school.lk. admin.school.lk. ( 2025010101 3600 900 604800 3600 )
@   IN NS  ns1.school.lk.
10  IN PTR ns1.school.lk.
20  IN PTR www.school.lk.
25  IN PTR mail.school.lk.

Managing and testing DNS

Terminal
nslookup www.school.lk 192.168.1.10
dig www.school.lk @192.168.1.10
dig MX school.lk
ipconfig /flushdns         # Windows: clear client cache
resolvectl flush-caches    # Linux

Management tasks: add, change and delete records, set suitable TTLs, keep secondary servers in sync, secure zone transfers (allow only listed secondaries), enable logging, back up zone files, and consider DNSSEC (signs records so answers can be verified).
