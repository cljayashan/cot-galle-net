Unit 5 · Server Installation, Setting Up and Configuration

5.8Hands-on lab: Build a Linux server

Do these tasks on your own computer or in the lab using free software. Write down what you see at each step: your notes are useful evidence for assessments and for revision.

  1. Install Ubuntu Server in a VM, set a static IP, install SSH and connect from your host.
  2. Install Apache, change the default page, and view it from another computer.
  3. Create a user, set file permissions and test access.
  4. List listening ports with ss -tulpn and justify each one.
  5. Install a Windows Server evaluation VM and add the DHCP and DNS roles.

Take a VM snapshot after each working step (installed, static IP, SSH, Apache). If a later change breaks the server, roll back in seconds instead of reinstalling.
