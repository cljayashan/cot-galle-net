Unit 5

Server Installation, Setting Up and Configuration

Why servers need a server OS, hosting options and server selection, installing Linux and Windows servers, remote access, server applications and ports.

What you will learn

After this unit you can:

  • Explain what a server is and why server operating systems and application software are required.
  • Compare dedicated, shared, VPS, cloud and virtual servers and select a suitable one.
  • Install and configure a server operating system.
  • Describe and use server access methods.
  • Install common server applications and tools.
  • Explain ports and manage them securely.
