3.2.6Verification commands

CommandPurpose
show running-configView active configuration
show mac address-tableSee learned MAC addresses
show vlan briefList VLANs and ports
show ip routeView routing table
show interfaces statusLink state of ports

What each command tells you

  • show running-config: the full configuration in use. Check that what you typed was really accepted (a typing mistake may have been rejected without you noticing).
  • show mac address-table: which MAC addresses the switch has learned, on which ports and in which VLANs. Use it to find which port a device is plugged into.
  • show vlan brief: each VLAN with its name and access ports. Check that every port is in the right VLAN.
  • show ip route: the routes a router knows. If the destination network is missing, packets for it are dropped (or follow the default route).
  • show interfaces status: every switch port with its state (connected or notconnect), VLAN, duplex and speed. It is the quickest way to spot an unplugged cable or a duplex mismatch.

More useful commands

CommandPurpose
show ip interface briefIP address and up/down state of every interface

show versionModel, software version, uptime and the reason for the last restart
show cdp neighborsDirectly connected Cisco devices, and the port that connects to each
show startup-configThe saved configuration, to compare with the running one
ping and tracerouteTest reachability from the device itself

Verification is a habit

After every change, verify it, before you move on. Change one thing, test it, then make the next change. If something breaks, you then know exactly which change caused it. Long show output can be filtered: for example, show running-config | include hostname shows only the lines that contain "hostname".

Tip: on a router, the do keyword runs a show command without leaving configuration mode, for example R1(config)# do show ip interface brief.

Remember

  • show commands prove that the configuration works; use them after every change.
  • show interfaces status and show ip interface brief quickly reveal ports that are down.
