5.1What is a server and why is a server OS required?

A server is a computer (or software) that provides services to other computers (clients) over a network. A server must run continuously, serve many users at once, be secure and be manageable remotely.

Server OS compared with a desktop OS

FeatureDesktop OSServer OS
PurposeOne interactive userMany simultaneous remote users and services
Hardware supportConsumer hardwareMulti-CPU, large RAM, RAID, hot-swap, ECC memory
Roles / servicesFewDNS, DHCP, web, file, directory, database, mail and more
Uptime and stabilityModerateDesigned for months or years without reboot
ManagementMostly local GUIRemote tools, command line, scripting, centralised policy
SecurityBasicFine-grained permissions, auditing, role-based access
LicensingPer deviceServer licence plus client access licences (CALs) for Windows; free/open source or subscription for Linux

Why application software is needed

The operating system manages hardware; server application software delivers the actual service: a web server (Apache, Nginx, IIS), database (MySQL, PostgreSQL, SQL Server), mail server (Postfix, Exchange), file server (Samba, SMB), DNS (BIND, Windows DNS). A server's purpose is defined by the applications installed, so the operating system and application stack must be chosen together to match the workload.
