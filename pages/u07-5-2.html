Unit 7 · Domain Name System (DNS)

7.5.2Windows Server DNS

  1. Server Manager > Add Roles and Features > DNS Server.
  2. Open DNS Manager, right-click Forward Lookup Zones > New Zone > Primary zone > name school.lk.
  3. Right-click the zone > New Host (A) to add records; tick Create associated PTR record if a reverse zone exists.
  4. Configure Forwarders (for example 8.8.8.8) on the server properties.
  5. Point clients' DNS setting to this server (usually through DHCP).

Checklist after the zone exists

  1. Create A records for servers students must reach.
  2. Create PTR records if mail or policy requires reverse DNS.
  3. Set forwarders for Internet lookups.
  4. On DHCP, push your DNS server IP to clients.
  5. From a client: nslookup www.school.lk and confirm the answering server is yours.

If clients still use 8.8.8.8 directly, they will never see your internal-only names.

Windows DNS in AD environments

On Windows Server, the DNS role often integrates with Active Directory. Creating a primary forward lookup zone for school.lk, then adding New Host (A) records (with optional PTR creation), gives names to servers and clients. Set forwarders (for example 8.8.8.8 or your ISP) so internal DNS can resolve Internet names. Point DHCP at your DNS server so clients learn it automatically.

Tip: dynamic updates can register client names automatically in AD-integrated zones — useful, but restrict who may update.

Remember

  • DNS Manager: zones, records, forwarders.
  • Clients must use your DNS IP (via DHCP) or they never see internal names.
