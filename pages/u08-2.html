8.2Firewall

A firewall is hardware or software that permits or blocks network traffic according to security rules, acting as a barrier between networks of different trust levels (for example the Internet and the LAN).

A firewall allows or blocks traffic using rules. It is usually the first technical control between an untrusted network and your servers, and it also runs as a host firewall on each machine.

Key words in this topic

  • Packet filter / stateful / proxy / NGFW / WAF: increasing awareness of connections and applications.
  • Default deny: block everything not explicitly allowed.
  • DMZ: network segment for public-facing servers.
  • ACL: access control list of permit/deny entries.
