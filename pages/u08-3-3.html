8.3.3Comparison and the hybrid approach

Comparison

FeatureSymmetricAsymmetric
KeysOne shared secret keyPublic and private key pair
SpeedFastSlow
Key distributionDifficultEasy (public key can be shared openly)
Typical useBulk data, disk and VPN encryptionKey exchange, digital signatures, certificates
ExamplesAES, ChaCha20RSA, ECC, Diffie-Hellman

Hybrid approach (how HTTPS works)

Real systems combine both: asymmetric cryptography (and certificates) authenticate the server and securely agree on a session key; then fast symmetric encryption protects the data.
