Unit 7 · Domain Name System (DNS)

7.5.1BIND9 on Ubuntu

Terminal
sudo apt install bind9 bind9utils -y

In /etc/bind/named.conf.local declare the zone:

Configuration file
zone "school.lk" {
    type master;
    file "/etc/bind/db.school.lk";
};

Create /etc/bind/db.school.lk:

Newer BIND versions also accept type primary;, the modern name for type master;.

DNS zone file
$TTL 3600
@   IN SOA ns1.school.lk. admin.school.lk. (
        2025010101 ; serial
        3600       ; refresh
        900        ; retry
        604800     ; expire
        3600 )     ; negative cache TTL
@     IN NS  ns1.school.lk.
ns1   IN A   192.168.1.10
www   IN A   192.168.1.20
mail  IN A   192.168.1.25
@     IN MX  10 mail.school.lk.

Check and apply:

Terminal
sudo named-checkconf
sudo named-checkzone school.lk /etc/bind/db.school.lk
sudo systemctl restart bind9

Remember to increase the serial number whenever you edit the zone. Also allow DNS in the firewall (sudo ufw allow 53).

Minimal zone mental model

SOA (zone meta + serial) → NS (who is authoritative) → A/AAAA (hosts) → MX/TXT as required. If dig against 127.0.0.1 works but LAN clients fail, check listen addresses, firewall UDP/TCP 53, and whether clients really use this server as their resolver.

BIND workflow

  1. Declare the zone in named.conf.local (zone name, type primary/master, file path).
  2. Create the zone file with SOA, NS, A/AAAA and other records.
  3. Run named-checkconf and named-checkzone school.lk /etc/bind/db.school.lk.
  4. Reload (systemctl reload bind9) and test with dig.
  5. Allow UDP/TCP 53 on the firewall only as required (authoritative to the world, or recursive only to your LAN).

Increase the serial (often YYYYMMDDnn) on every change so secondaries notice updates.

Remember

  • Check config → check zone → reload → dig.
  • Serial number changes are mandatory for transfers to see updates.
