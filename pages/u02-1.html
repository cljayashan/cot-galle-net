2.1What is a computer network?

A computer network is a set of devices (hosts) connected by links so that they can share resources and exchange data. Main purposes:

  • Resource sharing: files, printers, internet connection.
  • Communication: email, messaging, voice and video.
  • Centralised management: one place to manage users, security and backups.
  • Reliability and scalability: redundancy and the ability to grow.

Hosts, network devices and links

  • Hosts (end devices) are where data starts and finishes: PCs, laptops, phones, printers, servers and IP cameras. Each host needs a network interface and an address.
  • Intermediary devices pass data along the way: switches, routers, access points and firewalls (see 3.1). Users rarely see them, but every message goes through them.
  • Links (media) connect everything: copper cables, fibre and radio (see 1.6).

Each purpose explained

Resource sharing. One printer can serve a whole office, one Internet connection can serve hundreds of users, and files kept on one server can be used by everyone who needs them. This saves money and avoids keeping many copies of the same file, all slightly different.

Communication. Email, instant messaging, video calls and shared calendars all need a network. Today most businesses could not operate for a single day without them.

Centralised management. With a network, an administrator can create user accounts, apply security settings, install updates and back up data for hundreds of computers from one place, instead of visiting each machine.

Reliability and scalability. If one server fails, another can take over; if a link breaks, traffic can take another path. When the organisation grows, new devices are simply connected to the existing network.

Costs and risks

Networks also bring costs and risks that must be planned for: equipment and cabling, skilled staff to run them, and security threats, because every connected device is a possible way in for an attacker. A single fault in a central device can also stop many people working at once. Good design (see 2.8) and security (see Unit 8) reduce these risks.

Remember

  • A network is made of hosts, intermediary devices and links.
  • Networks share resources, enable communication, centralise management and improve reliability.
  • They also need investment, skills and security.

Hosts, devices and links in one picture

A host (PC, phone, server) runs applications. Intermediary devices (switches, routers, APs, firewalls) forward or filter traffic. Links are the cables or radio paths between them. Protocols agree how bits are framed, addressed and delivered so equipment from different vendors can interoperate.

Remember

  • Network = hosts + intermediary devices + media, speaking shared protocols.
  • Switches forward within a LAN; routers connect different networks.
