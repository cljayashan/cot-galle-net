9.4The "cannot reach the Internet" sequence

  1. ping 127.0.0.1 - is the TCP/IP software working on this computer?
  2. ipconfig /all - is the IP address valid (not 169.254.x.x)? Is the gateway correct?
  3. ping the default gateway - is the local network working?
  4. ping 8.8.8.8 - is the Internet reachable by IP?
  5. ping www.google.com - does DNS work? If this fails while step 4 works, the fault is DNS.
  6. tracert 8.8.8.8 - where does the path stop?
