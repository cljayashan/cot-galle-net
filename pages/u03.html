Unit 3

Network Devices and Protocols

The devices that build networks and how to configure them, the protocols they use, and the OSI and TCP/IP reference models.

What you will learn

After this unit you can:

  • Identify common network devices and state the function of each.
  • Install and configure a switch, router, access point and basic firewall.
  • Explain what a network protocol is and describe the most common protocols.
  • Describe the OSI and TCP/IP reference models and map devices and protocols to layers.
