Unit 7 · Domain Name System (DNS)

7.7Hands-on lab: DNS lookups and a DNS server

Do these tasks on your own computer or in the lab using free software. Write down what you see at each step: your notes are useful evidence for assessments and for revision.

  1. Use nslookup and dig to find the A, MX and NS records of three websites.
  2. Run dig +trace www.example.com and identify the root, TLD and authoritative stages.
  3. Build a BIND9 or Windows DNS server for school.lk (or another name you control; avoid .local, which is reserved for multicast DNS) with A, CNAME, MX and PTR records; point a client at it and test.
  4. Make a mistake on purpose (wrong serial or missing dot) and fix it using named-checkzone.
  5. Look up the registrar and expiry date of a domain with whois.
