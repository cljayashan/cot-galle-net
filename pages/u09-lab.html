Unit 9 · Network Troubleshooting

9.8Hands-on lab: Fault-finding exercise

Your teacher or a partner breaks one thing on a working lab network. Find and fix each fault using the method above and write a ticket for each:

  • Wrong subnet mask on a PC.
  • Wrong default gateway.
  • DNS server address typed incorrectly.
  • Web service stopped on the server.
  • Firewall rule blocking port 80.
  • Disconnected or wrong-VLAN port.
  • Disk full or stopped service on a Linux server.

Use the method: follow the "cannot reach the Internet" sequence for each fault and record it in a ticket like the sample in 9.7.
