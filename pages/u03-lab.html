Unit 3 · Network Devices and Protocols

3.5Hands-on lab: Devices, VLANs and packet capture

Do these tasks on your own computer or in the lab using free software. Write down what you see at each step: your notes are useful evidence for assessments and for revision.

  1. In Packet Tracer build: two PCs on a switch (192.168.1.0/24) and a server in a second network behind a router. Configure the router interfaces and test with ping.
  2. Create two VLANs and show that hosts in different VLANs cannot ping each other without a router.
  3. Run Wireshark, open a web page, and identify an Ethernet frame, IP packet, TCP segment and HTTP request. Write which OSI layer each belongs to.
  4. Capture a DHCP exchange (ipconfig /release then ipconfig /renew) and identify the four DORA messages.

Useful Wireshark display filters: dhcp (shows the DORA messages), http, dns, tcp.port == 80 and arp. Click a packet to see each layer's header in the middle pane.
