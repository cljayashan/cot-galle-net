Self-check questions

Write your answers first, then open the answers to check them.

  1. List four security settings you would apply to a new server and explain why.
  2. What does "default deny" mean in a firewall?
  3. Compare symmetric and asymmetric encryption (any three points).
  4. Which key does a sender use to create a digital signature, and which key does the receiver use to verify it?
  5. What problem does a digital certificate solve, and who signs it?
  6. Explain why HTTPS uses both asymmetric and symmetric cryptography.
  7. What is the purpose of a DMZ?
Show answers

  1. Any four, with reasons, for example:

    • Apply all updates: fixes known vulnerabilities that attackers scan for.
    • Disable unused services and ports: reduces the attack surface.
    • Strong passwords or SSH keys with MFA, no direct root login: stops brute-force and stolen-password attacks.
    • Host firewall with default deny: only required services are reachable.
    • Logging and monitoring with NTP time: incidents are detected and can be investigated.
    • Tested backups (3-2-1): data can be recovered after ransomware or failure.

  2. Everything is blocked unless a rule explicitly allows it.

  3. Symmetric uses one shared key, is fast and is used for bulk data; asymmetric uses a public/private key pair, is slower and is used for key exchange and signatures; symmetric has a key-distribution problem which asymmetric solves.

  4. The sender's private key signs; the receiver uses the sender's public key to verify.

  5. It proves that a public key belongs to a named owner, preventing impersonation; it is signed by a trusted Certificate Authority.

  6. Asymmetric cryptography authenticates the server and securely agrees a key, then faster symmetric encryption protects the bulk data.

  7. A DMZ isolates public-facing servers from the internal LAN so a compromised server does not give direct access to internal systems.
