2.4Network topologies

Topology describes how devices are arranged. Physical topology is the actual cabling layout; logical topology is how data flows.

TopologyDescriptionAdvantagesDisadvantages
BusAll devices on one shared cableCheap, little cableCable fault stops everyone; collisions
RingEach device connects to two neighboursOrderly accessOne break can disrupt the ring
StarAll devices connect to a central switchEasy to manage, fault isolationCentral device is a single point of failure
Mesh (full or partial)Devices interconnect directlyVery reliableExpensive; full mesh needs n(n-1)/2 links
Tree / HybridCombination of the aboveScalableComplex

The star topology with a switch is by far the most common in modern LANs.

Worked example: how many links does a full mesh of 6 devices need? 6 x 5 / 2 = 15 links.

Physical and logical topology

The physical topology is what you would see if you followed the cables. The logical topology is the path that data actually follows. They can be different: an old hub-based network was a physical star (every cable went to the hub), but a logical bus (the hub repeated every signal to everyone, as if they all shared one cable).

Each topology in more detail

Bus. All devices connect to one backbone cable, with a terminator at each end. Every device hears every transmission, so only one device can send at a time. If the backbone is cut, the whole network stops. It is now only of historical interest.

Ring. Each device connects to exactly two neighbours, forming a circle, and data travels around it. Older ring networks passed a token around: only the device holding the token could send, so there were no collisions. A single break can stop the ring, so many designs use a dual ring that can send traffic the other way around. Rings are still found in some metropolitan fibre networks.

Star. Each device has its own cable to a central switch. Adding or removing a device does not disturb anyone else, and a faulty cable only affects one device, which makes faults easy to find. The weakness is the centre: if the switch fails, every device connected to it is cut off. That is why important networks keep a spare switch, or use two switches.

Mesh. Devices have several connections to each other, so there are several possible paths. In a full mesh every device connects directly to every other device; in a partial mesh only the important ones do. The Internet's core and the links between important routers are partial meshes, so traffic can go around a failed link.

Tree / hybrid. A combination, such as several stars joined to a central backbone. Most large networks are hybrids: stars on each floor, joined by a backbone between floors and buildings.

Calculating mesh links

In a full mesh of n devices, each device connects to the other n − 1, and each link is shared by two devices, so the number of links is n(n − 1) ÷ 2. Each device needs n − 1 ports.

Remember

  • Physical topology is the cabling; logical topology is how data flows.
  • Star is the standard for LANs: easy to manage, but the central switch is a single point of failure.
