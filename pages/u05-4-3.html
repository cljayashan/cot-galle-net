Unit 5 · Server Installation, Setting Up and Configuration

5.4.3Windows Server first tasks

Use Server Manager to rename the computer, set a static IP (Network Connections), run Windows Update, and add roles with Add Roles and Features (or PowerShell: Install-WindowsFeature DNS -IncludeManagementTools).

PowerShell
Rename-Computer -NewName SRV1 -Restart
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.1.20 -PrefixLength 24 -DefaultGateway 192.168.1.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 192.168.1.10
Install-WindowsFeature DNS, DHCP -IncludeManagementTools
Get-WindowsFeature | Where-Object Installed

These PowerShell commands do the same jobs as Server Manager. Change the interface name (Get-NetAdapter lists them) and the addresses to suit your network.
