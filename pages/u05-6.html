Linux permissions: chmod 750 file gives owner rwx (7), group r-x (5), others none (0).

Services and permissions you will use daily

On Linux, a background service is often called a daemon. systemctl status apache2 shows whether it is running; enable makes it start at boot; restart reloads after config changes. Logs live under /var/log/ or in the journal (journalctl -u apache2).

Reading chmod 750

Permissions are owner / group / others, each with r(4), w(2), x(1):

  • 7 = 4+2+1 → owner read+write+execute
  • 5 = 4+1 → group read+execute
  • 0 → others nothing

So chmod 750 script.sh lets only the owner fully control the file and the group run it. Web content is often 644 for files and 755 for directories — group-writable web roots are a common vulnerability.

Remember

  • Install the application that matches the role, then manage it with the OS tools (systemctl, Services, Event Viewer).
  • Permissions and logging are part of administration, not extras.
