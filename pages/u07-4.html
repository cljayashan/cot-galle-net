Unit 7 · Domain Name System (DNS)

7.4DNS record types

RecordPurposeExample
AName to IPv4 addresswww IN A 192.0.2.10
AAAAName to IPv6 addresswww IN AAAA 2001:db8::10
CNAMEAlias to another nameweb IN CNAME www.example.com.
MXMail server for the domain (with priority)@ IN MX 10 mail.example.com.
NSName servers for the zone@ IN NS ns1.example.com.
PTRIP address to name (reverse lookup)10 IN PTR www.example.com.
SOAStart of Authority: primary server, serial, refresh timersone per zone
TXTFree text; used for SPF, DKIM, domain verification"v=spf1 mx -all"
SRVLocation of a serviceused by Active Directory, SIP

The trailing dot matters. In a zone file mail.example.com. is a complete name. Without the final dot BIND adds the zone name, so mail.example.com becomes mail.example.com.example.com.
