9.6Operating system and application troubleshooting

1Read the logs→2Check config syntax→3Check resources→4Check permissions→5Check recent changes
  • Check the logs first: the exact error message usually points to the cause. On Linux use sudo journalctl -u apache2 --since "1 hour ago" and tail -f /var/log/syslog; on Windows open Event Viewer (System and Application).
  • Check the configuration syntax before restarting a service (apache2ctl configtest, named-checkconf, nginx -t).
  • Check resources: disk full (df -h) is a very common cause of strange failures.
  • Check permissions and ownership of files and users.
  • Check recent changes: updates, new software, configuration edits. Roll back if needed.
  • Boot problems: use Safe Mode or Recovery Environment (Windows), rescue mode or GRUB recovery (Linux); restore from backup if the system is damaged.
  • Keep baseline records of normal performance so abnormal behaviour is easy to recognise.
