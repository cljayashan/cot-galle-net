Unit 5 · Server Installation, Setting Up and Configuration

5.2Types of servers (by role)

File server, print server, web server, application server, database server, mail server, DNS server, DHCP server, proxy server, authentication/directory server (Active Directory, LDAP), backup server, and virtualization host.

Each role in plain words

RoleWhat it doesTypical software
File serverStores shared folders and enforces permissionsSamba, Windows File Server
Print serverQueues and shares printersCUPS, Windows Print Server
Web serverAnswers HTTP/HTTPS requestsApache, Nginx, IIS
Database serverStores structured data for applicationsMySQL, PostgreSQL, SQL Server
Mail serverSends and receives emailPostfix, Exchange
DNS / DHCP serverNames and automatic addressesBIND, Windows DNS/DHCP
Directory / auth serverCentral usernames and policiesActive Directory, LDAP
Proxy serverForwards and can filter web trafficSquid, corporate proxies
Backup serverStores copies of other systemsBackup software + storage
Virtualization hostRuns many virtual machinesESXi, Hyper-V, KVM, Proxmox

One physical (or virtual) machine can run several roles if the load is light — for example DNS + DHCP + file shares on a small office server. Separate busy or sensitive roles (public web versus internal AD) onto different servers or VMs for security and performance.

Common mistake: putting a public website on the same server that holds all student or staff files without isolation. A web breach then reaches the files too. Prefer separate VMs and a DMZ (see Unit 8).

Remember

  • The role is defined by the service software, not by the box colour.
  • Small networks combine roles; larger ones separate them.
