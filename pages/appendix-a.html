AGlossary

Key terms used in this module, in alphabetical order.

TermMeaning
ACLAccess Control List: ordered permit/deny rules on a router or switch
AESAdvanced Encryption Standard; the common symmetric cipher
APIPAAutomatic Private IP Addressing: a 169.254.x.x address a client gives itself when DHCP fails
ARPAddress Resolution Protocol; maps IP to MAC on a LAN
BandwidthMaximum data capacity of a link
Broadcast domainPart of a network reached by a broadcast frame; routers separate broadcast domains
CACertificate Authority; trusted body that signs certificates
CIDRClassless Inter-Domain Routing; prefix notation such as /24
Collision domainPart of a network where frames can collide; each switch port is its own collision domain
CSMA/CACarrier Sense Multiple Access with Collision Avoidance, used by Wi-Fi
CSMA/CDCarrier Sense Multiple Access with Collision Detection, used by early half-duplex Ethernet
Default gatewayThe router interface a host sends traffic to for any destination outside its own subnet
DHCPProtocol that automatically assigns IP settings
Digital certificateAn X.509 document, signed by a CA, that binds a public key to an identity
Digital signatureA value created with the sender's private key that proves origin and integrity
DMZNetwork zone for public-facing servers
DNSSystem that translates names to IP addresses
DNSSECDNS Security Extensions: signs DNS records so answers can be verified
DORADiscover, Offer, Request, Acknowledge: the four DHCP messages
EncapsulationAdding a header (and trailer) at each layer as data moves down the stack
FirewallDevice or software filtering traffic by rules
FQDNFully Qualified Domain Name
GatewayRouter that links a network to others
HashFixed-length one-way digest of data
HypervisorSoftware that runs virtual machines
IPsecNetwork-layer VPN and security protocol suite
LatencyThe time data takes to travel from source to destination
MAC address48-bit hardware address of a network interface
NATTranslates private addresses to public ones
OSI modelSeven-layer reference model for communication
OUIOrganisationally Unique Identifier: the first 24 bits of a MAC address, identifying the manufacturer
PacketLayer 3 data unit
PDUProtocol Data Unit: the data unit at a layer (segment, packet, frame, bits)
PKIPublic Key Infrastructure; system managing certificates
Port16-bit number identifying a service on a host
RAIDCombining disks for speed and/or redundancy
Recursive resolverDNS server that finds an answer for a client by querying other servers, then caches it
RegistrarCompany that sells domain names
RSAWidely used asymmetric algorithm
SLAACStateless Address Autoconfiguration: IPv6 hosts build their own address from the router's prefix
SocketAn IP address plus a port number, for example 192.168.1.10:443
SSHSecure Shell; encrypted remote access
Subnet maskSeparates network and host parts of an IP address
TCP / UDPReliable / unreliable transport protocols
ThroughputThe data rate actually achieved on a link, always at or below the bandwidth
TLSTransport Layer Security; encrypts HTTPS and many other protocols
TopologyThe physical or logical arrangement of devices and links in a network
TrunkA switch link that carries several VLANs, with 802.1Q tags
TTLTime To Live: how long a DNS answer may be cached
VLANLogical network on a switch
VLSMVariable Length Subnet Masking
VPNVirtual Private Network
VPSVirtual Private Server
ZonePart of the DNS namespace managed by one set of servers
