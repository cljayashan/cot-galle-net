Unit 7 · Domain Name System (DNS)

7.3Name resolution step by step

A client wants www.example.com:

  1. The client checks its own cache and the hosts file.
  2. It asks its configured recursive resolver.
  3. If not cached, the resolver asks a root server, which refers it to the .com TLD servers.
  4. The TLD server refers it to the authoritative server for example.com.
  5. The authoritative server returns the IP address.
  6. The resolver caches the answer (for the TTL) and returns it to the client.

Queries use UDP port 53 (TCP 53 for large responses and zone transfers). Recursive queries ask the server to find the complete answer; iterative queries accept a referral.
