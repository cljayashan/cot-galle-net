3.2.5Wireless access point and home router

  • Connect to the admin page (for example 192.168.1.1) and change the default admin password.
  • Set a meaningful SSID and choose WPA2 or WPA3 with a strong passphrase.
  • Choose the least crowded channel; enable 5 GHz where possible.
  • Disable WPS and remote administration unless needed.
  • Update firmware.

Why each step matters

  • Change the default admin password. Default usernames and passwords (such as admin/admin) are published online. Anyone on your network could log in and take control of the router.
  • Use a meaningful SSID, and WPA2 or WPA3. WPA2 and WPA3 encrypt the traffic so it cannot be read over the air. Use a long passphrase (at least 12 characters, ideally a short sentence). Avoid putting your name or address in the SSID.
  • Choose a channel. On 2.4 GHz use 1, 6 or 11, whichever is least used by your neighbours. A free Wi-Fi analyser app on a phone shows the nearby networks. Use 5 GHz where devices support it: it is faster and less crowded.
  • Disable WPS. WPS (the "push button" or PIN setup) has known weaknesses, and its PIN can be guessed.
  • Disable remote administration. Then the router's admin page cannot be reached from the Internet.
  • Update the firmware. Updates close security holes that attackers already know about.

Extra good practice

  • Create a separate guest network for visitors. It gives them Internet access but keeps them away from your own computers, printers and cameras.
  • Place the access point centrally and high up, away from thick walls, metal and microwave ovens.
  • In a larger building, use several access points with the same SSID and security, on non-overlapping channels, so that devices can move between them (roaming). Businesses usually manage many access points from a central controller.
  • Use WPA2/WPA3-Enterprise in organisations, so that each user logs in with their own account and a leaver's access can be removed without changing the password for everyone.

Remember

  • Change default passwords, use WPA2/WPA3 with a long passphrase, and keep firmware updated.
  • Disable WPS and remote administration; use a guest network for visitors.
