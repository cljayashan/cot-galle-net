Recommended lab set-up

Everything in this module can be practised with free software on one computer:

  • A computer with at least 8 GB RAM and virtualization enabled.
  • VirtualBox or VMware Player to run virtual machines.
  • Ubuntu Server LTS ISO and a Windows Server evaluation ISO.
  • Cisco Packet Tracer (free from Cisco Networking Academy) for simulating routers and switches.
  • Wireshark for packet capture.
  • PuTTY or the built-in ssh client.

Study tip: do the labs. Networking and servers are practical skills; reading alone is not enough. Each unit ends with a hands-on lab page.

A routine for each unit

  1. Read the unit overview and its learning outcomes.
  2. Work through each short topic page, trying every command and interactive lab.
  3. Complete the hands-on lab and keep notes or screenshots.
  4. Answer the review questions before opening the answers.
  5. Tick the outcomes in the topic checklist.
