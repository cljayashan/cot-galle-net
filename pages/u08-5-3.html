8.5.3Practical: HTTPS certificates

Practical: enable HTTPS with Let's Encrypt (Ubuntu + Apache)

Terminal
sudo apt install certbot python3-certbot-apache -y
sudo certbot --apache -d www.example.com
sudo certbot renew --dry-run

This requires a real domain pointing to your server and ports 80/443 open.

Practical: create and inspect a self-signed certificate

Terminal
openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 365
openssl x509 -in cert.pem -text -noout
