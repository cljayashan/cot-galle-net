Self-check questions

Write your answers first, then open the answers to check them.

  1. What problem does DNS solve?
  2. List the components of the FQDN mail.dept.school.lk.
  3. Explain the difference between an authoritative and a recursive server.
  4. Which record type would you create for an email server and for an alias?
  5. What must you change in a zone file after every edit and why?
  6. State the steps to register a domain and make a website available on it.
  7. Which port and protocol does DNS use, and when does it use TCP?
Show answers

  1. It translates human-readable names to IP addresses (and other data) so people need not remember numbers.

  2. Host mail; subdomain dept; second-level domain school; TLD lk; root (.).

  3. An authoritative server holds the official records for a zone; a recursive resolver finds answers by querying other servers and caches them.

  4. MX (mail server, together with an A record for the mail host); CNAME (alias).

  5. Increase the SOA serial number so secondary servers know the zone changed and transfer it.

    1. Choose a name and check that it is available (registrar search or whois).
    2. Select the TLD and an accredited registrar.
    3. Register with your details and pay; enable WHOIS privacy, auto-renew, registrar lock and two-factor authentication.
    4. Set the name servers (registrar, hosting provider or your own).
    5. Create the records: A/AAAA for the website, MX for email, TXT for SPF and verification.
    6. Wait for propagation (depends on TTL) and test with dig.
    7. Upload the site to the server the A record points to, and renew the domain on time.

  7. UDP 53; TCP 53 for large responses and zone transfers.
