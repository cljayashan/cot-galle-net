4.4Subnet masks and CIDR

The subnet mask has 1s for the network part and 0s for the host part. CIDR notation writes the count of 1s: 255.255.255.0 = /24.

CIDRMaskHost bitsUsable hosts
/24255.255.255.08254
/25255.255.255.1287126
/26255.255.255.192662
/27255.255.255.224530
/28255.255.255.240414
/29255.255.255.24836
/30255.255.255.25222

Formulas:

  • Usable hosts per subnet = 2^h - 2 (h = host bits; subtract the network address and broadcast address).
  • Number of subnets = 2^s (s = bits borrowed from the host part).
  • Block size = 256 - the interesting octet of the mask.
