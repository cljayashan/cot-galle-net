2.6Ethernet and LAN technologies

Ethernet (IEEE 802.3) is the dominant wired LAN technology. Common standards:

Ethernet originally used CSMA/CD (listen, send, detect collisions). Modern full-duplex switched Ethernet has no collisions.

Wireless LAN (IEEE 802.11, Wi-Fi): uses CSMA/CA because wireless devices cannot detect collisions while transmitting. Key concepts: SSID (network name), access point (AP), channels (2.4 GHz and 5 GHz bands, plus 6 GHz in Wi-Fi 6E), and security modes (WPA2, WPA3; avoid the obsolete WEP).

Which Wi-Fi band? 2.4 GHz reaches further and passes through walls better, but it is slower and crowded; 5 GHz and 6 GHz are faster with more channels, but have a shorter range.

How Ethernet works today

Ethernet sends data in frames. Each frame contains the destination and source MAC addresses (see 4.1), a type field that says what is inside (usually an IP packet), the data, and a CRC check value at the end (see 1.8). A normal frame carries up to 1,500 bytes of data.

CSMA/CD: the old shared-cable method

On old shared cables and hubs, only one device could transmit at a time. CSMA/CD (Carrier Sense Multiple Access with Collision Detection) controlled this:

  1. Carrier sense: listen first; if someone else is sending, wait.
  2. Multiple access: if the line is quiet, any device may start sending.
  3. Collision detection: keep listening while sending. If two devices started at the same time, their signals collide; both stop, wait a random time, and try again. The random wait makes it unlikely that they collide again.

With a switch and full-duplex links, every device has its own private connection to the switch, so collisions cannot happen and CSMA/CD is not needed.

CSMA/CA in Wi-Fi

A wireless device cannot listen while it transmits, because its own signal drowns out everything else, so it cannot detect a collision. Wi-Fi therefore tries to avoid collisions instead: it listens, waits a random back-off time even when the channel seems free, then sends, and the receiver replies with an acknowledgement. If no acknowledgement arrives, the sender assumes something went wrong and tries again.

These are the theoretical totals for the access point. A single device usually gets much less, because the airtime is shared and walls and distance reduce the signal.

Channels

The 2.4 GHz band has only three channels that do not overlap (1, 6 and 11). If neighbouring access points use overlapping channels, they interfere with each other and everyone slows down. The 5 and 6 GHz bands have many more non-overlapping channels, so they suit busy buildings such as schools and offices.

Wi-Fi security

  • WEP: broken many years ago, and can be cracked in minutes. Never use it.
  • WPA2: uses strong AES encryption. Safe if the passphrase is long and hard to guess.
  • WPA3: the current standard. It protects against password-guessing attacks even when the passphrase is weak, and is preferred wherever all devices support it.
  • Personal mode uses one shared passphrase; Enterprise mode gives each user their own login through a central server, which is better for organisations.

Remember

  • Ethernet sends frames between MAC addresses; modern switched full-duplex Ethernet has no collisions.
  • Wi-Fi uses CSMA/CA with acknowledgements, because radios cannot detect collisions.
  • Use WPA2 or WPA3, never WEP.
