3.2.3Basic router configuration

Cisco IOS CLI
Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)# interface gigabitEthernet 0/1
R1(config-if)# ip address 10.0.0.1 255.255.255.252
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2
R1(config)# end
R1# copy running-config startup-config
R1# show ip route
R1# show ip interface brief

The prompt tells you where you are: R1> user mode, R1# privileged mode, R1(config)# global configuration, R1(config-if)# interface configuration. exit goes back one level; end returns straight to R1#, where show and copy commands are run.

What this configuration does

  • Interface G0/0 connects to the LAN. Its address, 192.168.1.1, becomes the default gateway for every PC on 192.168.1.0/24.
  • Interface G0/1 connects to the ISP using a small /30 network (10.0.0.0/30), which has exactly two usable addresses: .1 for R1 and .2 for the ISP router (see 4.4).
  • no shutdown is essential. Router interfaces are shut down by default, so an interface with an address but no no shutdown stays down.
  • ip route 0.0.0.0 0.0.0.0 10.0.0.2 is a static default route: "for any destination I do not know, send the packet to 10.0.0.2". Without it the router only knows its own two networks, and cannot reach the Internet.

Reading show ip route

The routing table marks each route with a code. C means a directly connected network, L is the router's own local address on that network, S is a static route, and S* marks the default route, which is shown as the gateway of last resort. If a network is missing from the table, the router cannot reach it.

Static or dynamic routing?

Static routesDynamic routing protocols (OSPF, EIGRP, BGP)
Typed in by the administratorLearned automatically from other routers
Simple, predictable, no extra trafficAdapt automatically when a link fails
Must be changed by hand when the network changesMore complex to configure, and use some CPU and bandwidth
Good for small networks and default routesNeeded for medium and large networks

Remember

  • Give each interface an address and no shutdown; the LAN interface is the hosts' default gateway.
  • A default route (0.0.0.0/0) sends unknown destinations to the ISP.
  • Check with show ip interface brief and show ip route.
