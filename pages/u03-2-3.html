3.2.3Basic router configuration

Cisco IOS CLI
Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)# interface gigabitEthernet 0/1
R1(config-if)# ip address 10.0.0.1 255.255.255.252
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2
R1(config)# end
R1# copy running-config startup-config
R1# show ip route
R1# show ip interface brief

The prompt tells you where you are: R1> user mode, R1# privileged mode, R1(config)# global configuration, R1(config-if)# interface configuration. exit goes back one level; end returns straight to R1#, where show and copy commands are run.
