Unit 9

Network Troubleshooting

A systematic way to find and fix faults: the troubleshooting method, layer-by-layer symptoms, command-line tools, common faults and documenting the fix.

What you will learn

After this unit you can:

  • Apply a systematic troubleshooting method.
  • Use command-line tools to diagnose network, DNS and server problems.
  • Troubleshoot operating system, application and network issues using logs and tools.
  • Document faults and solutions.
