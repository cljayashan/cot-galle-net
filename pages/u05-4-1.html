Unit 5 · Server Installation, Setting Up and Configuration

5.4.1Installation procedure

1Plan→2Back up→3Prepare media→4Boot→5Partition disks→6Admin account→7Network→8First boot tasks→9Document
  1. Plan: check hardware requirements, choose edition, note licence key, plan hostname, static IP, disk layout.
  2. Back up any existing data.
  3. Prepare media: download the ISO, verify its checksum, write to USB or attach to the virtual machine.
  4. Boot from media; choose language, keyboard and installation type (use Server Core / minimal where a GUI is not needed, which reduces attack surface).
  5. Partition disks (for example separate /, /var, /home on Linux; system and data volumes on Windows). Consider RAID.
  6. Set administrator account and a strong password.
  7. Configure network: static IP, mask, gateway, DNS.
  8. First boot tasks: set hostname and time zone/NTP, apply all updates, enable firewall, remove unneeded services, create a standard user for daily tasks.
  9. Back up the clean configuration and document it.

Why the order matters

Skipping "plan hostname and IP" leads to renaming and certificate pain later. Skipping "verify ISO checksum" risks installing from a corrupted or tampered image. Skipping "apply updates before exposing services" leaves known holes open on day one.

Minimal installs

On Windows, Server Core (no full desktop) and on Linux a minimal package set reduce what attackers can exploit and what you must patch. Add only the roles you need. You can still manage Windows Core with PowerShell and remote tools, and Linux with SSH.

Tip: write the hostname, static IP, mask, gateway, DNS and admin account in a build sheet before you start the installer. Tick each item after first boot.

Remember

  • Plan → media → install → network → harden → document.
  • Prefer minimal GUI/packages on servers facing the network.
