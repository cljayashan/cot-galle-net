2.9Network services at a glance

A typical LAN offers: file and print sharing, DHCP (automatic addressing), DNS (names), web, email, authentication (directory services) and internet access via a gateway. Later units show how to configure each.

Each service in a sentence

ServiceWhat it does for usersWhere it is configured
File sharingShared folders on a server, with permissions for each groupWindows File Server (SMB) or Samba on Linux (5.6)
Print sharingEveryone prints to shared printers through a print server, which queues the jobsPrint server role
DHCPGives every device its IP address, mask, gateway and DNS server automatically3.3.2 and 5.6
DNSTurns names such as intranet.school.lk into IP addressesUnit 7
WebIntranet sites and web applicationsApache, Nginx or IIS (5.6)
EmailSending and receiving mail inside and outside the organisationMail server or a cloud service
Authentication (directory)One username and password for every service, with central control of accountsActive Directory or LDAP
Internet accessShares the Internet connection, translates private addresses and filters trafficThe router (NAT, 4.3.2) and firewall (8.2)

How the services work together

When a student switches on a lab PC in the morning:

  1. DHCP gives the PC an IP address, the gateway address and the DNS server address.
  2. The student logs in; the directory service checks the username and password.
  3. Their home folder opens from the file server, found by name through DNS.
  4. They open the intranet in a browser: DNS finds the web server, which sends the page.
  5. They print a document, and the print server sends it to the lab printer.
  6. They visit an outside website: the request goes through the gateway, which uses NAT and the firewall to reach the Internet.

If any one of these services fails, users notice at once. That is why the following units show how to set up, secure and troubleshoot each one.

Remember

  • A LAN's main services are file and print, DHCP, DNS, web, email, authentication and Internet access.
  • The services depend on each other: DHCP and DNS in particular are needed by almost everything else.
