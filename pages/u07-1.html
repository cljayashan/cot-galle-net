Unit 7 · Domain Name System (DNS)

7.1Why DNS?

People remember names (www.example.com), computers route by IP addresses (93.184.216.34). DNS is a distributed, hierarchical database that translates names to IP addresses (and back), and it also stores mail routing and other information.

Life without DNS

Imagine typing 93.184.216.34 instead of a website name, and updating every bookmark whenever a server moves to a new IP. DNS stores the mapping in a distributed database so people use stable names while networks still route with IP addresses. It also answers questions like "which host accepts mail for this domain?" (MX records).

A lookup usually happens in milliseconds and is cached. When DNS fails, it often looks like "the Internet is down" even though ping to an IP still works — a classic troubleshooting pattern (see Unit 9).

Everyday example: you type www.school.lk. Your resolver finds an A record such as 203.0.113.10. Your browser then opens a TCP connection to that IP on port 443. DNS finished before the web traffic started.

Remember

  • DNS translates names ↔ IP addresses (and stores other data such as MX).
  • Users depend on DNS even when they never configure it manually.
